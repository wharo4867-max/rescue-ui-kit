# Rescue UI Kit

Biblioteca de componentes visuales para gestión de rescates y adopciones animales.

## Descripción

Rescue UI Kit es un Design System desarrollado con HTML5 y CSS3 puro. Su finalidad es organizar componentes visuales reutilizables para una interfaz de gestión de rescates y adopciones.

## Componentes desarrollados

1. **Botones:** primario, secundario y peligro.
2. **Formularios:** campos de texto y selección de especie.
3. **Tarjetas:** presentación de información de animales rescatados.
4. **Alertas y estados:** etiquetas de urgencia alta, media, baja y estado adoptado.

## Características técnicas

- Variables CSS definidas en `:root`.
- Modelo de cajas con `box-sizing: border-box`.
- Selectores, pseudoclases `:hover` y `:focus-visible`.
- Efectos visuales con `box-shadow`.
- Diseño adaptable mediante media queries.
- Componentes con clases reutilizables.
- Estructura semántica HTML5.
- Sin utilización de frameworks CSS.

## Archivos del proyecto

- `index.html`: estructura y contenido de los componentes.
- `style.css`: estilos, variables y diseño adaptable.
- `README.md`: documentación del proyecto.
